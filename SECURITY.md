# Política de segurança

O Scrapper Juris é mantido como aplicação local. Esta versão não deve ser exposta à internet, pois não implementa autenticação remota nem TLS.

## Reportar uma vulnerabilidade

Não publique detalhes exploráveis em issues públicas. Use o recurso **Private vulnerability reporting** na aba **Security** deste repositório, se estiver habilitado. Se não estiver, contate o mantenedor pelos canais privados associados à conta GitHub `joel299` e forneça passos mínimos de reprodução, impacto e versão afetada.

Não inclua credenciais, dados pessoais ou documentos judiciais sigilosos no relato. Remova ou mascare dados sensíveis antes do envio.
